# Android secure storage dependency review

## Candidates reviewed

### capacitor-secure-storage-plugin 0.10.0
- Explicit Capacitor 6 release.
- Android implementation uses AndroidKeyStore + SharedPreferences.
- Web fallback uses LocalStorage and is unacceptable for Demos political-opinion key material.
- Historical Android implementation includes RSA/ECB/PKCS1Padding paths for older API levels.
- Decision: **do not install yet**.

### @aparajita/capacitor-secure-storage 6.0.1
- Capacitor 6-compatible release.
- Documents Android AES-GCM encryption with a secret key generated by Android KeyStore and encrypted values stored in app-specific SharedPreferences.
- Web storage is unencrypted and therefore must also be rejected by the existing native-Android runtime guard.
- Decision: preferred candidate for deeper source/build review, not approved or installed by this commit.

## Mandatory acceptance criteria

A production dependency must:
1. support the repository's Capacitor 6 toolchain;
2. use Android Keystore-backed key material;
3. use authenticated encryption (AES-GCM or equivalent) for stored secret material;
4. never expose a web fallback through Demos;
5. support Android API levels actually targeted by Demos without insecure legacy downgrade;
6. pass lockfile/supply-chain review, native build, and physical-device tests;
7. preserve fail-closed behavior if secure storage becomes unavailable.

No dependency is approved by this document alone.
