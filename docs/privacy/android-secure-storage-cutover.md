# Android secure-storage cutover checklist

Status: prepared only; no native dependency installed and no production cutover enabled.

## Compatibility target
- DEMOS client currently uses Capacitor 6.x.
- Candidate dependency: @aparajita/capacitor-secure-storage 6.0.1 (Capacitor 6 generation).
- Do not install the current 8.x release into this branch without a Capacitor major upgrade review.
- Android behavior documented by the package: values are encrypted with AES-GCM using a secret key generated by Android KeyStore, then stored in app-specific SharedPreferences.
- Web implementation is unencrypted localStorage and MUST NOT be used by DEMOS for the opinion key.

## Intended wiring after explicit approval
1. Add exactly @aparajita/capacitor-secure-storage@6.0.1 to client dependencies and update the lockfile.
2. Run Capacitor Android sync/build checks.
3. Import the plugin only in the native Android bootstrap/composition layer.
4. Adapt the real plugin to AparajitaSecureStorageV6Port; keep the existing native-Android runtime guard before every operation.
5. Build createNativeAndroidCitizenOpinionVectorSourceFromIdentity with:
   - native Android runtime probe;
   - secure-storage plugin;
   - local ciphertext storage;
   - explicit vault cutover policy;
   - own-profile Identity request only for bootstrap migration.
6. installLivePoliticalMatchingSource(source) before assertLivePrivacyStartupReady().
7. Keep VITE_PRIVACY_OPINION_VAULT_CUTOVER=off until native device tests pass.
8. Test fresh install, bootstrap import, restart/read, tampered ciphertext, missing secure key, uninstall/reinstall, offline Research failure, and no legacy fallback.
9. Do not enable production cutover or delete legacy opinion rows as part of dependency installation.

## Security invariants
- Never call the plugin web implementation for production opinion-key storage.
- Never persist the raw AES opinion key beside the ciphertext.
- Existing corrupt ciphertext or missing device key must fail closed, not reimport.
- Privacy-first startup requires an installed local source.
- Identity bootstrap is one-time migration behavior, not the steady-state matching path.
