# 📞 Istruzioni per Contattare Supporto Axiom

## 🔗 Link Diretti

1. **Supporto Axiom**: https://axiom.co/support
2. **Documentazione Supporto**: https://docs.axiom.xyz/api-reference/support-and-config/getting-help
3. **Community Discord**: https://axiom.co/discord (per supporto rapido)

## 📧 Come Inviare il Messaggio

### Opzione 1: Email/Form Supporto
1. Vai su https://axiom.co/support
2. Compila il form di contatto
3. Copia il messaggio da `MESSAGGIO_SUPPORTO_AXIOM.md` (versione inglese)
4. Incolla nel campo messaggio
5. Allega screenshot se necessario

### Opzione 2: Discord Community
1. Vai su https://axiom.co/discord
2. Cerca il canale #support o #help
3. Pubblica il messaggio (versione inglese)
4. Include tutti i dettagli

## 📸 Screenshot da Includere (Opzionale)

1. **Impostazioni Token**:
   - Vai su Axiom → Settings → API Tokens
   - Seleziona "demosapp-backup"
   - Screenshot dei permessi

2. **Organization Settings**:
   - Vai su Axiom → Settings → Organization
   - Screenshot che mostra l'Organization ID

3. **Error Response**:
   - Screenshot dell'errore 403 dalla console/log

## ⏱️ Tempi di Risposta

- **Email/Form**: 24-48 ore
- **Discord**: Più veloce (ore/minuti se online)

## 💡 Cosa Aspettarsi

Il supporto probabilmente chiederà:
1. Conferma dell'Organization ID
2. Verifica dei permessi del token
3. Log dettagliati delle richieste
4. Possibile test con un nuovo token

## ✅ Dopo il Contatto

1. **Aspetta risposta** dal supporto
2. **Segui le istruzioni** che ti danno
3. **Aggiorna il token** se richiesto
4. **Riprova la migrazione** dopo la risoluzione
